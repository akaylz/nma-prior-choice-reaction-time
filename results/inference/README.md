# Reaction-time inference results

All results use all valid completed choices and treat the mouse as the independent unit.
Positive effects mean slower prior-incongruent movement initiation.

## Primary results

- **0% contrast:** median I−C +20.1 ms (95% whole-mouse bootstrap CI +12.3 to +26.1 ms; 95/139 positive mice; Holm-adjusted sign-test p=1.82e-05).
- **6.25% contrast:** median I−C +18.7 ms (95% whole-mouse bootstrap CI +12.1 to +23.1 ms; 103/139 positive mice; Holm-adjusted sign-test p=2.27e-08).
- **12.5% contrast:** median I−C +14.0 ms (95% whole-mouse bootstrap CI +10.8 to +19.5 ms; 111/139 positive mice; Holm-adjusted sign-test p=2.04e-12).

## Contrast dependence

The repeated-measures Friedman test did not find evidence that effect magnitude differed across contrasts (χ²=1.68, p=0.431).
The numerical 20.1 → 18.7 → 14.0 ms sequence must therefore not be described as a significant trend.

The result is associative rather than causal.
